Frequently Asked Questions

Answers to common questions about data imports, reports, database setup, and user roles.

View Documentation
What database does CrDr Report use by default?
By default, CrDr Report runs with an embedded, persistent file-based H2 database in MySQL compatibility mode (stored at ./data/crdr.mv.db). No external MySQL server is required to start using the application. You can switch to MySQL at any time using --spring.profiles.active=mysql or by overriding DB_URL, DB_USERNAME, and DB_PASSWORD.
How do I import an existing Microsoft Access (.mdb) accounting file?
Sign in, open Upload Company (.mdb) from the Company Selection page (/upload), and select your .mdb file. CrDr Report uses UCanAccess in-process to read companies, account heads, opening/closing balances, daybook entries, and schedules—no Microsoft Access installation is needed. If your .mdb file is password-protected, configure the CRDR_MDB_PASSWORD environment variable.
What columns are required for Daybook CSV uploads?
Your CSV file must include a header row with these exact column names: Sno,TDate,Narration,acccode,dramt,cramt,stkvalue. Ensure you have selected an active company first on /company_selection before uploading on /uploadcsv.
How do I export a Ledger report to PDF?
Open Ledger from the Reports Dashboard (/findLedger), choose the account head and date range, and generate the report. On the Ledger view, click the PDF export action (/pdfLedger) to generate a formatted JasperReports PDF under the pdf/ directory.
What is the difference between user, admin, and developer roles?
  • user: Can upload companies/CSVs, switch between their own companies, and generate all financial reports.
  • admin / developer: Has all user capabilities plus user management (/create_user, /users, /delete_user), full Actuator endpoints, and H2 Console access (when enabled).
Are financial numbers formatted in Indian Rupee grouping?
Yes. Amounts use en-IN locale formatting (e.g., 1,25,000.00) and BigDecimal precision for Ledger, Trial Balance, Trading & P&L, and Balance Sheet calculations.
