Quick Start

CrDr Report runs on Java 8+ with Spring Boot 2.7.18 and requires zero external database setup out of the box.

.\mvnw.cmd clean package
java -jar target/CrDrReport-0.0.15-SNAPSHOT.jar

Open http://localhost:8080 in any desktop or mobile browser and sign in via /login.

Database Configuration

By default, CrDr uses file-based H2 in MySQL mode. Override any setting with environment variables or activate the mysql profile:

Variable Default Purpose
DB_URL jdbc:h2:file:./data/crdr;MODE=MySQL;NON_KEYWORDS=YEAR;AUTO_SERVER=TRUE JDBC connection string (H2 or MySQL)
DB_USERNAME sa Database username
DB_PASSWORD (empty) Database password
DB_DDL_AUTO update Hibernate schema strategy (none, validate, update)
H2_CONSOLE_ENABLED true Enable/disable /h2-console (set false in prod)
CRDR_MDB_PASSWORD (empty) Password for encrypted .mdb Access uploads

Financial Reports

  • Daybook (/findDaybook): Daily voucher listing by date range.
  • Ledger (/findLedger): Account-level transactions with opening balance and JasperReports PDF export (/pdfLedger).
  • Trial Balance (/findTrialBal): Consolidated debit and credit balances across all accounts.
  • Trading & P&L (/findTradingPL): Gross and net profit/loss calculation.
  • Balance Sheet (/findBalSheet): Schedule-grouped assets and liabilities.

Security & Roles

All report and upload endpoints require authentication. User creation uses BCrypt hashing with a minimum 8-character password policy. Administrative routes (/create_user, /delete_user, /users, /h2-console/**, /actuator/**) are restricted to admin and developer roles.
